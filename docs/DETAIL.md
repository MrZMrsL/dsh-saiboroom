# 赛博房间 · dsh-saiboroom

DeepSeek Harness 的一页侧栏面板：**会变心情的角色 + 你的账 + 你的想法 + 你的待办 + 每晚的沉淀**。

不是挂在角落的小人，是一页能看出「你今天怎么过的」的房间。

## 卡片一览

- **心情**：0–100 + 六根情绪（开心/踏实/甜/心疼/担心/难过）。悬停能看到每根情绪受什么影响。分数会写进系统提示词，**真的改变她说话的口气**。
- **饭量账本**：按真实模型（Flash / Pro）计价，7 日柱状 + 按项目分组；一碗饭 = 1 元，缓存命中率单独显示（命中价是未命中的 1/50）。
- **额度守护**：设月上限，超 80% 琥珀、超 100% 品红并给降档建议。
- **总账单 · 按模型** / **各会话在用哪个模型**：逐事件读 provider/model，换模型、多会话混用都分别记账并外推月末。
- **我现在在干什么** / **别的会话在干什么**：会话标题、你最后说的那句、谁在跑、谁刚停。
- **待办**：`笔记/40-待办.md` 与 dtodo 四轨**合并**显示（每条标来源），**都能直接点勾**。
- **随录**：随手记一句回车落盘；每条可点「记住 / 待办 / 舍弃」。
- **记忆检索**：本地 md 切块索引（中文 2 字滑窗 + 同义词表 + 字符 bigram 余弦），1–10ms，不联网。
- **笔记本 · 卡在哪**：读 `笔记/00-当前.md`。
- **今天的日报**：21:30 后自动写 `笔记/日报/<日期>.md`，**纯计算、不调模型、不花钱**。
- **今晚的梦**：把今天过一遍，挑 3–6 条值得留的写进 dsh-memory-evolve 的待确认队列（与已落盘记忆去重），去留在记忆 Tab 里定。

页头：轻刷新 ⟳（只重拉数据）、更新时刻、改名。

## 装

```bash
git clone https://github.com/MrZMrsL/dsh-saiboroom.git
cd dsh-saiboroom
node build.cjs            # 可选：仓库里已带编译产物
```

在 DSH 里：

```
plugin_manager install_bundle target=<这个目录的绝对路径>
```

看到 `application: applied` 后 **Ctrl+F5**，侧栏出现新的一行，点进去就是它。

换版本：`remove_bundle` 再 `install_bundle`（同版本直接装会报 `already-installed`）。宿主半边热重载，客户端改动要刷新页面。

## 配置（`~/.dsh/dsh-room/config.json`，或面板里点「改名」）

```json
{
  "name": "赛博房间",
  "userName": "老郑",
  "agentName": "大肥鱼",
  "workspace": "F:\\你的项目目录",
  "budget": 200
}
```

- `name` 这一页叫什么；`userName` 怎么称呼你（默认系统用户名）；`agentName` 怎么称呼她；`workspace` 笔记与日报的根目录（默认跟随最近会话的工作目录）；`budget` 月度上限（元，0=不设）。

> ⚠️ **改名谨慎**：名字只影响这一页怎么写，不会改记忆与人格文件。但改多了，旧记忆里存的是老称呼，翻记录时容易错乱——建议第一次就定下来。

## 数据在哪

| 内容 | 路径 |
| --- | --- |
| 心情 / 配置 / 日志 / 沉淀记录 | `~/.dsh/dsh-room/` |
| 待办 / 随录 / 当前状态 / 日报 | `<workspace>/笔记/` |
| 长期记忆 / 待确认队列 | `~/.dsh/memories/`（由 dsh-memory-evolve 管，本插件只读 + 入队） |

**不联网**。唯一的外发是「心情判定」与「今晚的梦」——用你当前会话自己的模型各发一次小请求（约 600 tokens / 1–3K tokens）。不想花就说一声停掉。

## 依赖与边界

- 宿主半边零第三方依赖，只用 Node 内置模块，不 import 任何 `@deepseek-ai/*`（link 装的插件解析不到）。
- 客户端只用宿主提供的 React，不重复打包。
- 只读 DSH 的会话事件与本地 Markdown，不复制、不上传会话历史。
- 没有 7×24 的后台意识：只在你发消息、或定时任务到点时活着。

## 换自己的角色

1. 绘图 AI 出图：1024×1024、**纯品红 #FF00FF 底**、像素风硬边、无文字；每个状态出 2 张「同姿势、只动一点点」的差帧。
2. 抠底只抠「从四条边连通的品红」，别全图按色替换（角色身上的同色装饰会被抠出洞）。
3. 替换 `assets/chara/`：`main/think/work/eat/proud/sleep.png`（336×336）+ `anim_*.png`（两帧横条 600×300）+ `icon.png`（64×64）。
4. `node build.cjs` → 重装 → 刷新。

状态机：23–7 点或心情 <42 → 睡；150s 内有工具事件 → 干活；刚回完话 2.5min 内 → 吃饭；心情 <62 → 思考；≥78 → 得意；其余待机。
